## 4. Key Architectural Takeaways

1. **Memory Footprint**: Velo's compiled native runtime operates with single-digit megabyte baseline working sets, consuming significantly less memory than garbage-collected or JIT-managed runtimes.
2. **Zero-Overhead Native Performance**: In file scanning and compute-intensive loops, Velo compiles directly to native code via standard C99/GCC, achieving speeds on par with C and Rust.
3. **Async I/O Velocity**: Velo's event loop (`loop_run`) and non-blocking socket architecture match or exceed traditional threaded or event-driven servers while maintaining predictable latency percentiles.
